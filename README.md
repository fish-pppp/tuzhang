# 途账

旅行 AA 分账：记下谁付了钱、谁一起摊，实时算出总支出、每个人已付 / 应付，以及该收还是该给谁转。

示例同行：yeah、欣欣、yuki、林子苑、陈世节、硬件、傅哥。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可。不登录也能记账（存在浏览器里）；登录后会把当前账单同步到账号。

## 功能

- 上方人头：点选某人，看 TA 相关账单和结余
- 记一笔：金额、谁付的、谁一起 AA
- 每个人：已付、应付、还要付 / 应收
- 怎么还：最少转账次数的结清建议
- 管理同行：加人、改名、移出

## 部署

本仓库可直接接到 Vercel：Import GitHub 仓库后用默认 `npm run build` 即可。
